Skill normalization

A hash map turns synonyms into one standard skill. If a word is not in the map, Levenshtein string similarity (80% or higher) catches typos like "Typescrpt".

Rank candidates for a job

Each candidate gets a compatibility score from 0 to 100. A min-heap keeps only the top K, so ranking stays fast on large pools.

Assign candidates to roles

Each role has one opening and each candidate can take one role. The Hungarian algorithm on the candidate–job bipartite graph finds the assignment with the highest total score.

Minimum team skill coverage

Which is the smallest group of candidates whose skills cover everything the open roles need? Greedy set cover gives a quick answer; an exhaustive search confirms the true minimum on small pools.

About the project

The engine automates recruitment by matching résumés to job postings, normalizing skill vocabularies, scoring compatibility, assigning candidates to roles and reporting the minimum skill set for a team. It reduces manual screening and supports faster, data-driven hiring.
